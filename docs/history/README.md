# History

This directory preserves exploratory and superseded research: earlier
models, roadmaps, and progress notes that later work corrected, replaced,
or moved past. It is kept for provenance, not as guidance — nothing here
should be treated as describing the current state of the project or the
current plan.

For the current state and plan, start at the root
[`README.md`](../../README.md) and [`docs/project-status.md`](../project-status.md).

Files here carry a banner explaining what superseded them and pointing at
the current replacement. If you're reading one of these documents because
it turned up in a search and it doesn't have such a banner, treat that as a
gap to fix (add one pointing at whatever in `docs/` now covers the same
ground) rather than as license to trust the file as current.
